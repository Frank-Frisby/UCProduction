# production volunteer hub — prototype

A test build of the volunteer training hub app, built on the Production brand guide.

This is a static, self-contained HTML file — no backend, no build step, no real data.
It's meant for testing the look and navigation flow with real volunteers before
committing to a full build with live Planning Center and Google Calendar data.

## What's in here

- `index.html` — the entire app (one file, plain HTML/CSS/JS)

## Screens

- **Home** — greeting, continue-training carousel, departments, recently added
- **Library** — filterable list of training videos, docs, and photos
- **Player** — training video detail with chapters and progress
- **Schedule** — Planning Center serving schedule (read-only) + Google Calendar team events/birthdays
- **Team** — basic roster

## Status

Placeholder content throughout. No real videos, docs, or live integrations yet.
This is for testing look, feel, and navigation only.
